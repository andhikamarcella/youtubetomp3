# Security Policy

## Supported Versions

YTConv is currently under active development and maintained on the main production branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | ✅ Yes             |
| Older builds | ❌ No       |

Only the latest deployed version on https://ytconv.up.railway.app/ is officially supported with security updates.

---

## Reporting a Vulnerability

If you discover a security vulnerability in YTConv, please report it responsibly.

### 📩 How to Report

Please DO NOT create a public GitHub issue for security vulnerabilities.

Instead, report it privately via:

- Email: help.ytconv@proton.me   
  *(replace this with your real email)*

Include the following information:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any proof-of-concept (if available)

---

## ⏱ Response Time

You can expect:

- Initial acknowledgment within 48 hours
- Investigation within 3–7 business days
- A fix deployment as soon as possible if confirmed

---

## Responsible Disclosure

We appreciate responsible disclosure and will:

- Investigate all legitimate reports
- Credit researchers (if desired)
- Fix confirmed vulnerabilities promptly

Abuse, spam, or non-security related issues will be ignored.

---

## Scope

This policy applies to:

- https://ytconv.up.railway.app/
- The official GitHub repository
- Backend processing and API endpoints

Third-party services (e.g., Railway, YouTube, npm packages) are outside the scope of this policy.
