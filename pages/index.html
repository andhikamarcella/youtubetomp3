01 · Instalasi

Pilih perangkatmu

Node.js 22.14+ dan npm 10+ diperlukan, kecuali iSH yang memakai frontend Python.

Windows

Pasang Node.js LTS resmi, buka CMD baru, lalu:

npm.cmd install -g ytconv@1.7.3
ytconv.cmd repair
ytconv.cmd doctor

macOS

brew install node@24 python ffmpeg
npm install -g ytconv@1.7.3
ytconv repair && ytconv doctor

Arch · CachyOS

sudo pacman -Syu --needed nodejs npm python python-pip ffmpeg
npm install -g ytconv@1.7.3
ytconv doctor

Ubuntu · Debian

sudo apt update
sudo apt install nodejs npm python3 python3-pip ffmpeg
node --version  # harus 22.14+
Jika Node terlalu lama →

Fedora

sudo dnf install nodejs npm python3 python3-pip ffmpeg-free
node --version
npm install -g ytconv@1.7.3

openSUSE

sudo zypper install nodejs npm python3 python3-pip ffmpeg
node --version
npm install -g ytconv@1.7.3

Android · Termux

pkg update
pkg install nodejs python ffmpeg
termux-setup-storage
npm install -g ytconv@1.7.3

iPhone/iPad · iSH

Gunakan frontend Python. Node.js tidak diperlukan.

02 · Penggunaan

Satu sintaks, banyak hasil

Video MP4 1080pytconv URL --mode video --video-format mp4 --resolution 1080
Audio MP3ytconv URL --mode audio --audio-format mp3 --audio-quality 320
Transkripytconv transcript URL
Metadata + subtitleytconv extract URL
Salinan 4Kytconv URL --mode video --upscale 4k

Upscale 4K memakai Lanczos lokal di FFmpeg. Resolusinya nyata 3840×2160, tetapi tidak diklaim menciptakan detail AI yang tidak ada pada sumber.

03 · Akses akun

Cookies hanya bila diperlukan

YTConv mencoba akses publik dulu. Untuk media yang memang boleh diakses akunmu, login di situs resmi lalu gunakan profil browser:

ytconv download "URL" --cookies-browser chrome
Jangan pernah kirim cookies.txt.

Jangan unggah ke GitHub, chat, email, screenshot, atau log. Cookies tidak melewati DRM, paywall, wilayah, atau izin akun.

Jika harus mengekspor berkas, gunakan Get cookies.txt LOCALLY untuk browser Chromium atau cookies.txt untuk Firefox, pilih format Netscape, lalu hapus berkas setelah dipakai.

04 · Aman & legal

Tutorial web, bukan web ripper

Halaman ini tidak menerima URL dan tidak memproses media. Konversi berlangsung lokal agar URL, IP, dan sesi akun tidak diserahkan ke situs ripper pihak ketiga.

Gunakan dengan izin

Simpan hanya media milikmu atau media yang memang diizinkan untuk diunduh. Jangan melewati DRM, paywall, wilayah, atau izin akun.

Offline resmi YouTube

Untuk fitur offline resmi, gunakan tombol Download yang disediakan YouTube/YouTube Premium bila tersedia.

Buka YouTube Help →

Deno bukan login

Deno membantu yt-dlp menjalankan tantangan JavaScript. Ia tidak menggantikan cookies, akun, PO Token, atau izin akses.

AI yang jujur

1.7.3 memakai upscale Lanczos teruji. Paket tidak mengklaim AI super-resolution karena model AI portabel belum divalidasi pada semua perangkat.
