# Support and bug reports

Email: [help.ytconv@proton.me](mailto:help.ytconv@proton.me)

Before reporting a problem, run:

```bash
ytconv --version
ytconv --diagnose
ytconv doctor
```

Include your operating system, Node.js version, requested mode/format, and the sanitized error text. Do not include cookies, tokens, passwords, OTP codes, private URLs, browser profiles, or account identifiers.

For reproducible public bugs, open a [GitHub issue](https://github.com/andhikamarcella/YTConv/issues). Provider behavior can change independently; a site-specific failure does not necessarily mean every format or platform is broken.
