# Shell and terminal guide

YTConv 1.7.2 supports CMD, PowerShell, POSIX shells, WSL/SSH, Termux, and the iSH Python frontend. Start with [Platforms](PLATFORMS.md), [Node.js](NODEJS.md), and [Troubleshooting](TROUBLESHOOTING.md).

Use `npm.cmd` and `ytconv.cmd` on Windows if PowerShell blocks generated `.ps1` shims. Do not weaken the execution policy just to run the CLI.
