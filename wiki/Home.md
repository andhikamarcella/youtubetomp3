# YTConv 1.7.2 Wiki

YTConv is a cross-platform terminal downloader and converter for media you own or are authorized to save.

## Start here

- [Formats and repeat conversion](Formats-and-repeat-conversion)

Quick verification:

```bash
npm install -g ytconv@1.7.2
ytconv --version
ytconv repair
ytconv doctor
```
