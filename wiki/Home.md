# YTConv 1.7.3 Wiki

YTConv is a cross-platform terminal downloader and converter for media you own or are authorized to save.

Quick verification:

```bash
npm install -g ytconv@1.7.3
ytconv --version
ytconv repair
ytconv doctor
```
