Kebijakan Cookie

YTConv menggunakan cookie dan storage browser untuk sesi login, sesi admin HttpOnly, CSRF, preferensi tampilan, status PWA, dan pemulihan pengalaman pengguna.

Cookie admin bersifat server-side, HttpOnly, Secure di production, dan tidak perlu disalin ke browser storage. Cookie YouTube yang dipakai server untuk konversi tidak pernah ditampilkan melalui API publik.

Analytics internal, jika diaktifkan, hanya menyimpan event non-sensitif seperti page_view atau status_viewed dan tidak menyimpan URL lengkap, cookie, password, atau token.

Kamu dapat menghapus cookie melalui pengaturan browser. Menghapus cookie dapat membuat sesi keluar, preferensi hilang, atau fitur tertentu meminta login ulang.
