Pedoman Komunitas

Forum, chat, private room, voice signaling, dan tiket harus digunakan untuk bantuan dan diskusi yang aman.

  • Dilarang spam, flood, phishing, malware, pelecehan, doxxing, ancaman, atau konten ilegal.
  • Dilarang mengirim token, cookie, password, API key, dokumen identitas, atau data sensitif orang lain.
  • Lampiran harus relevan dan aman. Upload berbahaya, file terlalu besar, atau file yang menyamar dapat ditolak.
  • Gunakan fitur report/block bila tersedia. Admin dapat menyembunyikan, menghapus, atau membatasi konten dan akun yang melanggar.

Tindakan moderasi penting dicatat secara aman untuk audit internal dan tidak menampilkan rahasia kepada publik.
