Kebijakan Privasi

YTConv memproses URL/media yang kamu kirim untuk menjalankan fitur konversi, metadata, subtitle, tiket dukungan, forum, profil, dan fitur tambahan.

File hasil dan file sementara dapat disimpan terbatas untuk menyelesaikan proses, caching singkat, dan pembersihan otomatis. Jangan unggah data rahasia melalui tiket/forum.

Data tiket seperti nama, email, pesan, dan lampiran digunakan untuk membantu dukungan. Konfigurasi Firebase/Cloudinary/Turnstile digunakan sesuai kebutuhan fitur dan tidak menandakan afiliasi resmi.

YTConv tidak berafiliasi dengan YouTube, Google, Spotify, SoundCloud, Cloudflare, atau layanan sumber media lain.
