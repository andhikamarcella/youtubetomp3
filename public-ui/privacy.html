Kebijakan Privasi

Terakhir diperbarui: 2 Juli 2026. Ringkasan ini menjelaskan data yang diproses YTConv secara jujur sesuai fitur aplikasi.

Data yang diproses

YTConv memproses URL media yang kamu masukkan, pilihan format/kualitas, status antrean, file sementara, hasil konversi, dan metadata teknis yang dibutuhkan untuk menyelesaikan konversi.

Jika kamu memakai akun, forum, profil, rewards, dukungan, tiket, atau upload bukti, aplikasi dapat memproses nama tampilan, email, avatar, pesan, lampiran, status tiket, chat tiket, laporan komunitas, dan riwayat tindakan yang relevan.

Log operasional dapat berisi request ID, status respons, durasi, kategori error, user agent ringkas, dan identitas aman yang telah diminimalkan. URL sumber penuh, cookie YouTube, token, dan rahasia tidak ditujukan untuk analytics atau log publik.

Pihak ketiga

  • Google/Firebase dapat dipakai untuk login, profil, forum, tiket, atau penyimpanan data aplikasi bila dikonfigurasi.
  • Cloudinary dapat dipakai untuk upload gambar, lampiran, cover, atau file media yang memang kamu unggah melalui fitur terkait.
  • Cloudflare Turnstile dipakai untuk verifikasi anti-bot pada aksi tertentu.
  • Provider AI hanya digunakan saat kamu membuka fitur AI Navigator; jangan masukkan rahasia atau data sensitif ke prompt.
  • Analytics internal bersifat privacy-friendly dan hanya mencatat event non-sensitif jika fitur analytics diaktifkan.

YTConv tidak berafiliasi resmi dengan YouTube, Google, Spotify, SoundCloud, Cloudflare, Cloudinary, Firebase, atau platform sumber media lainnya.

Retensi dan penghapusan

File output, temp, cache, metadata job, analytics, tiket, dan audit log mengikuti konfigurasi retensi server. File sementara dapat dihapus otomatis setelah kedaluwarsa atau saat pembersihan storage berjalan.

Kamu dapat meminta akses, koreksi, atau penghapusan data melalui halaman Permintaan Data. Permintaan diproses sebagai tiket dukungan agar statusnya bisa dilacak.

Keamanan

Jangan mengirim cookie, bearer token, API key, password, atau kredensial lain melalui tiket/forum. Admin tidak akan meminta rahasia tersebut lewat halaman publik.

Halaman admin dilindungi server-side dan data sensitif tidak dimasukkan ke halaman publik. Jika kamu menemukan masalah keamanan, gunakan halaman kontak atau tiket dengan detail secukupnya tanpa membocorkan data pihak lain.
