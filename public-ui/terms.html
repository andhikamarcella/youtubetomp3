Ketentuan Penggunaan

Gunakan YTConv secara bertanggung jawab dan sesuai hukum yang berlaku.

Penggunaan yang diizinkan

Kamu hanya boleh memproses konten yang kamu miliki, konten yang berlisensi untuk kamu gunakan, domain publik, atau konten yang secara eksplisit mengizinkan download atau pemrosesan.

Kamu bertanggung jawab memastikan URL, upload, subtitle, metadata, cover, lampiran, forum post, dan prompt AI yang kamu kirim tidak melanggar hak pihak lain.

Batas dan larangan

  • Dilarang memakai layanan untuk pelanggaran hak cipta, spam, scraping massal, malware, phishing, doxxing, atau pelecehan.
  • Dilarang mengunggah HTML, executable, SVG berbahaya, atau file yang menyamar sebagai gambar/lampiran aman.
  • Dilarang mencoba mengakses admin, tiket, room privat, file hasil, atau data pengguna lain tanpa izin.
  • Fitur dapat dibatasi oleh rate limit, antrean, maintenance, konfigurasi provider, atau kebijakan sumber media.

Akun, komunitas, dan tiket

Login Google/Firebase, forum, private room, voice/chat, rewards, dan tiket dapat dikenai aturan komunitas, moderasi, penghapusan konten, pembatasan akun, dan audit admin yang aman.

Jangan memasukkan data sensitif ke tiket, forum, room privat, atau prompt AI. Admin dapat meminta informasi tambahan tetapi tidak akan meminta password atau API key.

Tidak ada afiliasi resmi

YTConv tidak berafiliasi resmi dan bukan layanan resmi YouTube, Google, Spotify, SoundCloud, Cloudflare, Firebase, Cloudinary, atau platform lain yang mungkin terhubung melalui fitur aplikasi.
