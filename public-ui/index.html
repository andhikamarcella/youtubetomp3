                  FAQ
                  
          
                  
          
                  
            
                  
              Apakah subtitle yang diunduh lengkap?
              
                  Ya. Tombol Ambil subtitle menarik transkrip penuh dari YouTube, menyimpan berkas .srt, .txt, serta menampilkan teks lengkap yang bisa disalin.
                  
            
                  
            
                  
              Bagaimana cara mempercepat proses convert?
              
                  Gunakan tips interaktif di atas: pilih M4A, abaikan playlist, dan pastikan binary terbaru. Aktifkan Auto-download agar hasil langsung tersimpan.
                  
            
                  
            
                  
              Bisakah hasilnya dibagikan ke perangkat lain?
              
                  Setelah convert, buka kartu preview dan pilih tombol QR. Kode tersebut dapat dipindai dari ponsel sehingga file bisa diunduh tanpa menyalin tautan.
                  
            
                  
            
                  
              Mengapa perlu upload cookies.txt?
              
                  Beberapa video dibatasi usia/login. Unggah cookies.txt valid melalui pengaturan agar proses tetap lancar.
                  
            
                  
            
                  
              Format apa yang cocok untuk kebutuhan saya?
              
                  Pilih M4A/AAC untuk ukuran kecil, FLAC/AIFF untuk mastering, dan MP4/WEBM jika butuh video lengkap. Resolusi video dapat diatur pada menu Resolusi Video.
                  
            
                  
            
                  
              Bisakah situs ini dipakai offline?
              
                  Ya. Klik ikon install di browser (Add to Home Screen) untuk memasang versi PWA. Service worker menyimpan shell aplikasi sehingga masih bisa membuka riwayat dan FAQ saat offline.
                  
            
                  
            
                  
              Bagaimana dengan kontrol suara dan narrator?
              
                  Aktifkan switch Voice & Narrator di Experience Hub. Narrator akan otomatis membacakan status jika mode otomatis dinyalakan, sedangkan tombol Voice menjalankan perintah seperti “convert sekarang”.
