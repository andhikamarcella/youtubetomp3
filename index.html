Jika video yang sama sudah pernah didownload dengan setelan yang sama dalam 24 jam terakhir, server langsung melempar file yang sudah ada (Waktu tunggu = 0 detik!).

                      Browser Anda mungkin menyimpan *cache* versi website yang lama. Coba lakukan **Hard Refresh** (CTRL + F5) atau buka lewat mode Incognito/Private. Jika server baru diupdate, jangan lupa minta Admin restart node servernya.
